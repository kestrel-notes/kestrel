今天

一打开就是今天这一页

左边是这一年的热度，中间是今天写的，右边替你把这一篇的来路摆好：大纲、局部图谱、出链、别人怎么指过来。写下 [[某篇]]，那一篇的正文就直接嵌在这一页里读。

从「今天」开始用

图谱

写够几十条，笔记会长出自己的形状

按 Ctrl+G 全屏打开。哪个主题圈了最多篇、哪两堆之间只有一条线连着，一眼看得出来。

怎么用图谱

Markdown

你已经会的那些写法，全都算数

表格、任务列表、代码高亮、脚注、公式、Mermaid 流程图，写下去就是排好的。想看原始的 .md 长什么样，按 Ctrl+Shift+M 切到源码档。

支持的语法清单

双链与嵌入

一句话，可以指回另一篇

打两个左方括号 [[，名字自己冒出来。想整段搬过来，前面再加一个感叹号 ![[。还没写的那一篇不会红着报错——它画成虚线，等你补上就自己连上。

链接、别名与嵌入

查询块

在正文里问一句，答案长在页面上

「本周还没做完的文章」——写成一块，它就一直替你查。列表、表格、日历几种摆法都有，问完能存成模板下次直接用。

写第一个查询块

四张安全网

删掉的东西不会偷偷消失

删除先进回收站；正文每改一次自动留一版，右栏翻得到；给主题改名前先告诉你全库会动到几处；每天落一份快照，挑一份点一下就装回去。

找回一篇删掉的

键盘

手不用离开主键盘区

Ctrl+K 打开命令面板，想不起键位就搜名字。Ctrl+O 跳到某一篇，Ctrl+F 全站搜索，Ctrl+, 改外观。

全部快捷键

外观

白桦、麦秸、松林、薄荷

两套亮色两套暗色，都能跟随系统深浅。嫌颜色不够，把自己的 .css 丢进 snippets 文件夹就生效。这一页右上角那四个小圆点，就是这四套。
