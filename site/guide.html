Kestrel 使用说明

从记下第一条，到把删掉的东西找回来。

第一次打开

第一次运行时库里是空的。Kestrel 会自动建一个「Kestrel 使用指南」主题和 4 篇示例文章，另外帮你打开今天这一篇日记。

  1. 直接在中间开始打字。写日记不需要新建，今天这一篇已经在那里了。
  2. 要按主题写文章，点左栏第二个视图「主题」，再点「新建文章」。
  3. 示例看完就可以删。它们都挂在同一个主题下面，删掉不会影响你自己写的任何一篇。

这 4 篇示例是特意留下的：双链、反向链接、图谱、标签树、属性分组、大纲，这六样都要先有内容才看得见。

界面长什么样

窗口分三栏：左边选要看什么，中间写字，右边显示当前这一篇的相关信息。

  • 左栏有四个视图：今天 Ctrl+1、主题 Ctrl+2、标签 Ctrl+3、属性 Ctrl+4。
  • 中间是正文。顶部那一排小标签是你打开着的几篇。
  • 右栏从上到下依次是：大纲、反向链接、出链、局部图谱、属性、历史版本、编年史，每一块都能单独滚动。
  • 底部的状态条显示三件事：存没存、当前是哪一种编辑模式、有没有开专注模式。

下载与安装

安装包在 Releases 页，文件名是 Kestrel-<版本>-setup.exe。支持 Windows 10 和 Windows 11（64 位），装在你自己的账户里，不需要管理员权限，安装向导是中文的。

只有 Windows 桌面版：没有手机版，没有网页版，也没有 Mac 和 Linux 版本。

  1. 下载之后可以核对一下文件指纹。在 PowerShell 里运行：Get-FileHash .\Kestrel-0.1.0-setup.exe -Algorithm SHA256。
  2. 第一次运行时 Windows 会弹一次蓝色的 SmartScreen 提示。安装包没有做代码签名（就是没买证书），这不代表文件有问题。点「更多信息」，再点「仍要运行」。
  3. 装完打开，就可以开始写了。

v0.1.0 的安装包大小是 156,349,540 字节，SHA-256 以 Releases 页上写的那一串为准（当前是 c05094725873d13369e38f62af172b184f1f5c8c2b46c1689ffa032e54c88ba9）。

不想用发布出来的安装包，也可以拉源码自己打包：先 npm install，再 npm run dist。

写和存

  • 日记按日期存，一天一篇；文章挂在主题下面。两种记录的写法完全一样。
  • 不需要按保存键。停止输入半秒就存一次，右下角会显示「已保存」。想马上存就按 Ctrl+S，它顺便帮你留一个历史版本。
  • 编辑器有三种模式，按 Ctrl+Shift+M 依次切换：阅读（只看）、所见即所得（正常写）、源码（看原始 Markdown）。
  • 切到源码模式之前，Kestrel 会先检查一遍，确认这些文字存出去还能一个字不变地拿回来，才让你切。如果可能会改动你的内容，它就停在原来的模式，并告诉你是哪几处。
  • 长文章里可以收起小节：点标题左边的折叠箭头，或者按 Ctrl+K 搜「全部折叠」一次全收。
  • 选中一段文字，右下角会显示这一段有多少字。

把一段想法变成一篇文章

  1. 在日记里选中那句话。什么都不选也可以，那样会把整篇日记升成一篇文章。
  2. 按 Ctrl+K，搜「升格」，回车。
  3. 选一个主题，确认。内容和格式会一起搬过去，日记里留下一行指回去的链接。

反过来也可以：在文章里输入 [[2026-09-26]]，就能指回那一天的日记。

常用的 Markdown 写法都支持

不需要学新的语法。下面这些写下去就是排好的样子：

  • 标题、列表、任务项（- [ ] 待办）、引用、分割线。
  • 表格：输入 | 就会开始建表，也可以按 Ctrl+K 搜「插入表格」。建好之后能用鼠标加行加列。
  • 代码块：三个反引号开头，后面写语言名，有语法高亮和行号。mermaid 比较特殊，见下面两条。
  • Callout：一行以 > [!注意] 开头，就是一只带图标的小提示框。
  • 公式：行内写 $E=mc^2$，单独一行写 $$…$$。
  • 脚注：正文里写 [^1]，文末写 [^1]: 出处。
  • Mermaid 图：代码块的语言写 mermaid，图会直接画出来。语法写错了也不会吞掉你的文字，它会退回成代码块，并把错误原因显示出来。
  • 图片和附件：拖进窗口，或者复制后用 Ctrl+V 粘贴都可以。文件会存到数据库旁边的 attachments/ 文件夹里。

双链与嵌入

在正文里输入两个左方括号 [[，就会弹出一个候选列表，里面是主题名、文章标题，还有「今天」「昨天」这类日期写法。

  1. 用 ↑ ↓ 选择，按 Enter 确定。
  2. 按 Esc 只会关掉这个列表，你已经打出来的那部分文字原样留着。
  3. 想让它显示成另一句话，加一个竖线：[[向量数据库|那几家向量库]]。
  4. 想把那一节的正文整段搬过来，在前面再加一个感叹号：![[那一节#小节名]]。只想指过去、不搬内容，用 [[#小节名]] 指向同一篇里的某一节。
  5. 想知道链接那头写了什么，按住 Ctrl 把鼠标停在链接上，会弹出一张小卡片，显示那一篇的第一段和它被指向了几次。还没写的文章也会弹，而且这一种最有用：它会告诉你这个写法已经被用了几处。

还没写的那一篇：链接会显示成虚线，不会标红，也不会报错。等你哪天把那一篇写出来，它就自动变成实线。

一个写法指向哪里，你可以自己定：按 Ctrl+K 搜「别名」，会打开一个小窗口。在里面把 [[玻璃]] 这样的写法绑定到某个主题或某篇文章上，正文一个字都不用改。给主题改名时，它会问你要不要「旧名留作别名」。这条别名在同一个窗口里能看到也能删；删掉之后，用到它的几处会变回虚线，不会悄悄不见。

右栏的两块：「反向链接」列出别的文章是怎么指到这一篇的，每条都带着上下文那一行；「出链」列出这一篇指向了哪里，哪几条还是虚线。下面偶尔会出现一组「未链接提及」——意思是别处直接打了这一篇的名字，但没有写成链接。它一行列一处，点「连上」只改你点的那一处。

标签与属性

标签是写在正文里的词。输入 #JVM/调优，左栏的标签树里就会长出这一支。中文标签不用加空格，#云铝股份 也算一个标签。点父标签，它下面的子标签会一起被筛出来。

属性是当前这一篇的结构化字段，在右栏最上面那块「属性」里填：

  • 类型有四种：文字、数字、清单、勾选。同一个属性名在整个库里只用一种类型，填错了它会直接说哪里不对。
  • 填好之后，左栏第四个视图「属性」会按取值分组：状态 = 进行中 的文章归在一组，状态 = 读完 的归在另一组。

收藏：在这一篇按 Ctrl+D，标题栏的星标里能看到全部收藏。

大纲在右栏。长文章不用一路滚到底，点大纲里的某一行就跳到那一节。

查询块：在正文里问一句

  1. 按 Ctrl+K 搜「插入查询块」，正文里会出现一个可以输入条件的块。
  2. 把条件写清楚，比如 状态=进行中 标签包含 机器学习。日期也可以直接写 今天 或 最近 7 天。
  3. 结果就显示在这个块里，有五种显示方式：列表、表格、卡片、日历、统计条。
  4. 常用的那句可以存成模板，下次一键插入。模板管理在同一个窗口里。

存进数据库的是查询条件本身，不是查出来的结果。所以它会跟着导出、跟着备份，换一台电脑照样能查出东西来。

图谱：看看你的笔记长成了什么形状

  • 看这一篇的邻居：右栏那块小图，显示两跳以内的关系。颜色区分日记、文章和主题，虚线表示链接指向的那一篇还没写出来。
  • 看整个库：按 Ctrl+G 打开全屏图谱。可以拖动、可以缩放到某一堆、也可以按主题收拢。
  • 按时间看：按 Ctrl+Shift+G 切到时间轴视图，那里有按月份的密度格子，以及跨年同一天的提示。
  • 「反复提到」在右栏：如果同一句话你在三个以上不同的月份里写过，而写它的那几篇之间一条链接都没有，这一格就会把它们列出来，每行写着「跨 7 个月 · 10 篇彼此没连」。要不要处理由你判断。点「整理成一篇」只会新建一篇空标题、把这几篇的链接写进去，原来那几篇它一篇都不动。整个库的清单可以按 Ctrl+K 搜「思想重复度」打开。

搜索

按 Ctrl+F 输入关键词，搜整个库（正文也搜，不只标题）。排序有三档：综合、相关度、最近。想优先看最近的，选「最近」。

只记得大概的名字？按 Ctrl+O 用快速切换比搜索更快，它只在记录和主题里挑。

同时打开几篇

  • 按 Ctrl+T 在新标签里打开，Ctrl+W 关掉当前标签，Ctrl+Tab 在标签之间轮流切换，Ctrl+Shift+← / Ctrl+Shift+→ 把当前标签左右移动一位（也可以直接用鼠标拖）。
  • 在侧栏的文章卡片上按 Ctrl+单击，或者点鼠标中键，都会新开一个标签。中键点一篇已经打开的文章是切过去，不会多开一个。
  • 双击标签就是固定它。固定的标签永远排在最前面，Ctrl+W 关不掉，要先取消固定。
  • 每个标签记住自己的滚动位置、光标位置和编辑模式。关掉应用再打开，上次开着哪几篇、它们的顺序、当前是哪一个、各自滚到哪里，都会恢复成原样。

演示模式和随机打开

要给别人看的时候：按 Ctrl+K 搜「演示这一篇」。

  • 在两个段落之间单独占一行写 --- 就是分页（写 ***、___、- - - 也一样）。演示时一屏一页，页脚显示 3 / 12。
  • 往前翻：→ ↓ Space PageDown；往后翻：← ↑ Backspace PageUp；Home 和 End 跳到首尾。点屏幕左半边或右半边也能翻页。Esc 退出。翻到最后一页就停住，不会循环，也不报错。
  • 代码块里面的 --- 不算分页，所以贴 diff 不会莫名其妙多出几页。
  • 整篇只有一页时会给你一句提示，不会把整篇当一页放出来让你以为功能坏了。
  • 演示时的字号比编辑时大一档，这只是显示放大，正文内容一个字都不改。演示期间 Ctrl+K、Ctrl+W、Ctrl+Tab、Ctrl+, 都不生效：不该有标签被关掉、文档被换掉。退出来，原来那个标签还在原地。
  • 没有演讲者视图、备注和计时、自动播放。

想随便翻翻以前的：按 Ctrl+K 搜「随机」。它会新开一个标签，不会把你正在写的那一篇关掉，屏幕上也会告诉你是哪一篇。连续按不会重复，回收站里的不参与。这个命令没有默认快捷键。

把一篇发给别人看

按 Ctrl+K 搜「分享这一篇」。当前这篇会写成一个 .html 文件：里面没有一行 JavaScript，也不会联网。断网、换电脑、过十年，双击都能打开。

  • 图片直接封在这一个文件里，旁边不用再带一个 assets/ 文件夹。
  • 公式用 MathML 显示（不带走那 1 MB 字体），Mermaid 只带已经渲染好的那张 SVG。
  • 写文件之前它会自己再检查三遍：没有脚本、没有外部链接、没有你电脑上的路径。有一项不过就不写这个文件。

这个功能不是发布，也不是托管：没有上传、没有短链接、没有别人能访问的地址。发给谁，内容就在谁那里。

导出与导回

按 Ctrl+K 搜「导出为 Markdown」。整个库会导出成一棵目录树，每篇一个 .md 文件；标题、主题、标签、属性写在每个文件开头的 frontmatter 里。用 Obsidian 那类编辑器打开，看到的就是这个形状。

搜「从 Markdown 导回」可以把那棵目录树再导回来。它认的是自己写在包头里的那串 kestrel-id，所以同一篇导回去不会产生重复。

这一对功能只保证自己导出去、再自己导回来。别的软件导出来的目录它一个字都不读——这是有意这么定的：要照顾的格式太多，照顾不全反而会把现有的库弄乱。

删掉了怎么找回来

  1. 回收站：删除是软删除，先进回收站（标题栏那个垃圾桶图标）。找到那一条点「恢复」，指向它的链接也一起接回来。满 30 天之后才会在启动时清掉，而且只有当天那份快照已经写到盘上时才动手。不想等，可以在设置的「数据」那一栏里点「跑一次 30 天那一刀」。回收站里的东西也可以随时点「彻底删除」，那一下是立刻生效的。
  2. 历史版本：在右栏最下面那格「历史」。每改动一次自动留一版（同一篇两次之间至少隔 5 分钟，不然列表会变成一串「3 秒前 / 6 秒前」），每篇最多留 50 版。按 Ctrl+S 强制留一版，不受这个时间限制。选一版点「恢复」——恢复之前会先把当前这一版存下来，所以连恢复这一步本身也能撤销。
  3. 改名之前先告诉你数量：给主题或标签改名时，弹层会先写「全库有 N 处会被改」，然后在动手之前先给那 N 篇各留一版历史。
  4. 数据库文件本身：卸载应用不会删除 %APPDATA%\Kestrel。

备份与恢复

  • 启动时如果当天还没有备份过，就往 %APPDATA%\Kestrel\backups\ 写一份，默认保留最近 7 份（可以设成 3 到 30 份）。设置里有一个开关可以关掉它。
  • 备份列表里每一份都写着日期、篇数和大小。选一份点「换过去」，整个库就回到那个时刻。换之前，当前的库会先自动存成 kestrel-before-restore-…，所以两个方向都能退回去。
  • 不要靠复制 .db 文件来备份：应用开着的时候，最近的改动还在 -wal 这个文件里，没有回写到主文件。只拷主文件，拿到的是一部缺了最新改动的库。
  • 备份只存在本机，不上传任何地方。附件在旁边的 attachments/ 里，不跟着备份走，所以把备份文件拿到另一台电脑上恢复，附件那些位置会是空的。

换电脑：把 kestrel.db 和 attachments/ 这两样拷过去就够了。老版本（还叫 keeNote 的时候）升上来的机器，第一次启动会把旧位置的文件复制一份到新位置，旧的那份原样留着当退路。

数据放在哪里

  • 一个文件：Windows 下在 %APPDATA%\Kestrel\kestrel.db（SQLite）。
  • 零网络请求：没有统计、没有自动更新检查、没有云。字体也打包在安装包里。正文里的 http 链接被点击时交给系统浏览器打开，应用内不会开新窗口。
  • 多台电脑之间同步 = 你自己挑一个文件夹：按 Ctrl+K 搜「文件夹同步」。推，就是往那个文件夹里写一份完整的库加一份记录信息；要换回来就走上面那条恢复的路。把这个文件夹放进 Dropbox、OneDrive 或 Syncthing，是那些软件在同步，不是 Kestrel 在发请求。那一份是明文的完整日记——它在谁的云盘账号里，你的日记就在谁那里。
  • 两边都改过时，它不替你猜：比较的是「相对上次同步，哪一边动过」。两边都动过就停下来，把两边的篇数和最后改动时间并排列出来，两个按钮由你选。
  • 那个文件夹里除了 Kestrel 自己写的两个文件，出现的其他 .db（比如同步盘的冲突副本）Kestrel 一概不读、不删。

这个版本会自己删东西的地方只有一处：回收站和历史版本满 30 天后，会在启动时被彻底删除，而且只有当天那份快照已经写到盘上时才动手。除此之外，程序不会自己删掉你的任何内容。

还有一件事它不会替你做：同步没有定时器，推和拉两个按钮都在人手上。

换外观

按 Ctrl+, 打开设置。里面有六栏：外观、编辑器、片段、快捷键、数据、关于。每一项设置都会存进数据库，重启之后还在。

  • 四套主题：白桦（亮色，默认）、麦秸（亮色，适合长文阅读）、松林（暗色，默认）、薄荷（暗色，高对比）。勾上「跟随系统」就会在亮色和暗色之间自动切换。强调色也有几档预设。
  • 字号是整条字号阶梯一起调，不是只放大正文。
  • 毛玻璃效果可以关掉。关掉之后背景变成实色，长文读起来背景不会跟着透。

想改得更深：把你的 .css 文件放进 %APPDATA%\Kestrel\snippets\，放进去就生效，删掉就撤回。

  • 生效顺序按文件名从小到大，跟你什么时候存的没关系。两个文件改了同一条选择器，文件名靠后的那个生效。
  • 设置里那一栏能看到每个文件的大小和修改时间，也可以单独关掉某一个（关着的状态重启之后还是关着）。超过 1 MB 的文件不生效，但会照样列出来，后面写着为什么没生效。
  • 写错了、界面被自己藏起来了？按 Ctrl+K 搜「暂停全部片段」，或者启动时加 --no-snippets。暂停只管这一次运行，不会改动任何勾选。
  • 踩过的坑：直接改类选择器最稳（像 .md-prose { … } 这种，不用 !important 就盖得住）。要改主题变量得写成 body[data-theme] { --text-1: … }——写成 body {} 或 :root {} 压不住主题那一层。
  • 片段是文件，不存在数据库里：每日备份、导出、恢复都不会带上它们。
  • 片段里写 @import url(http://…) 或者引用外部背景图都连不出去，CSP 会当场拦下。这跟「零网络请求」那句承诺是同一件事。
